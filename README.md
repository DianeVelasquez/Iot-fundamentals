# Internet of Things (IoT) 🌐⚡

This repository contains my work and practices developed during the **Internet of Things (IoT)** course.

The repository includes basic web integrations, Arduino Uno implementations, electronic circuit simulations in Fritzing, and technical documentation related to the practices completed throughout the subject.

## ✨ Highlights

- Basic web exercises using PHP and HTML.
- Arduino Uno motor implementation practices.
- Electronic circuit simulations and diagrams created with Fritzing.
- Organized documentation for practices and experiments.
- Introductory IoT development and hardware/software interaction.
